# 物理实验室 · Chrome 扩展

独立的初中物理离线学习扩展，按《义务教育物理课程标准（2022年版）》组织七个模块：64 节讲解与自测、48 个 WebGL 三维交互实验、10 个实践项目。离线课程无需后台，AI 问答与讲解共用 GESP 后台，支持笔记本和小屏幕。当前版本 2.1.0。

## 安装与打开

1. 在 Chrome 地址栏输入 `chrome://extensions`。
2. 打开右上角“开发者模式”，点击“加载已解压的扩展程序”。
3. 选择本目录（有 `manifest.json` 的这一层）：

   ```text
   D:\books-angent\physics-lab-extension
   ```

4. 在 Chrome 工具栏的扩展菜单中找到“物理实验室”，点击图标，在独立标签页中打开。也可以通过扩展的“选项”打开。

不需要安装 npm 依赖或编译。更新代码后，在扩展管理页点击该扩展的重新加载按钮，再刷新学习页面。不要直接双击 `index.html`，浏览器的文件协议会限制 JavaScript 模块加载。

顶栏以状态圆点和“已连接／未连接／待配置／需更新”显示共享后台状态，点击标签展开模型、连接详情及操作菜单。网页模式（地址以 `http://` 开头）下，菜单中的“重新检测”检测连接，“启动说明”列出本机启动步骤。若后台未启动，双击本目录的 **`start-learning.bat`**；更新后台则双击 **`restart-learning.bat`**。这两个入口与 `manifest.json` 同层，调用同级 `gesp-lab-extension` 的现有脚本，因此两个目录需要放在同一个父目录下。当前工作区可直接运行 `D:\books-angent\physics-lab-extension\start-learning.bat`。扩展模式仍支持页面上的“启动／更新后台”。

45 个新增实验均采用三维网格、深度、光照和透视相机，提供参数调节、实时读数、三步探究、最多 12 组记录及笔记。步骤会实际切换实验条件；动态过程手动播放，静态光路等实验通过参数与对照步骤观察。知识地图列出 22 类学生实验的模型入口，实物测量、小制作和调查由 10 个实践项目提供材料、过程、证据要求及报告。完整范围见 [内容与验证说明](docs/V2-COVERAGE.md)。

左上角按钮可收起模块导航；窄屏以抽屉显示，支持关闭按钮和 Esc。课程上一节／下一节、实验记录／重做／播放按钮随滚动保持可达。各模块独立显示进度、课程检索和自测成绩。

声学涵盖声音的产生、传播、声速与回声、音调、响度、音色、声的利用、噪声控制。提供知识点检索、回声测距计算器、噪声措施分类、已学标记与本机实验笔记。

三个声学实验分别是：

- **音叉与悬球**：静置 → 敲击观察 → 止振 → 再敲击，使用转换法呈现振动证据。
- **真空罩中的电铃**：保留空气 → 减少空气 → 理想真空 → 放回空气，保持声源工作状态不变。
- **声的三个特性**：建立基准 → 只改频率 → 只改振幅 → 改变谐波组成 → 自主探究，包含真实频率的合成音试听和统一时间窗口的波形图。

鼠标拖动或单指拖动旋转，滚轮或双指缩放；画布获得焦点后，方向键旋转，`+` / `-` 缩放，`Home` 复位。实验可在页面内展开，点击退出或按 `Esc` 返回。每步需手动播放；切换步骤、修改参数、离开页面、隐藏标签页时停止动画和试听。

## 上海中考题（100 道选编）

首页上方、侧栏和顶栏都有“上海中考题”入口。现收录 **100 道题，涉及 2014—2025 年间的 11 个年份**，覆盖七个知识模块，包含选择、填空、计算和实验探究。按年份、模块、对应章节、题型和关键词组合筛选；关键词也能匹配知识点与章节名。每页 10 道，翻页与筛选保留草稿，进度统计针对全部筛选结果。顶部翻页栏靠右排列并吸附在顶栏下方；切页后首题保持可见，小屏幕自动换行。

每题显著标注 **年份、题号、对应章节与具体知识点**。章节使用本应用的课程目录，不代表某一版教材的章次；综合题同时关联多个章节，跨模块题可从各相关模块找到。章节名称可直接跳转课程；课程侧栏的“开始做题”打开本节全部相关题目。每题保留独立链接，原 20 道题的链接与作答记录继续有效。

## 题目讲解与原创变式（共用 GESP 后台）

每道中考题提供“讲解课件与变式题”入口。一次生成 6～12 页讲解和三道原创变式：逐页包含读题、知识、思路、步骤、易错、总结，正文与详细讲稿分开，支持目录跳转、上一页／下一页、讲稿朗读、数据表和分步图解。三道变式依次为巩固、同等、进阶，显示与原题相比改变的条件、关联章节和知识点，支持提示、独立作答、答案核对与解题自评。

物理和 GESP **共用 `gesp-lab-extension/learning_service` 的同一进程、端口、模型配置与任务队列**，无需另起物理后台，也不需要再填一份密钥。默认地址为 `http://127.0.0.1:8766`。更新后先在 GESP 页面点击“启动／更新后台”，再重新加载物理扩展；也可运行 `gesp-lab-extension/restart-learning.bat`。后台端口有调整时，在物理讲解页“GESP 共享后台”中填写相同地址。共享服务也直接提供物理页面：`http://127.0.0.1:8766/physics/`。

物理课件与变式一起保存在 GESP 的 `.local/physics/`，与编程课件、练习分开。原题只保留一份当前版本，全部生成与校验成功后才替换；失败保留旧内容。同题重复生成受任务队列限制。浏览器使用独立 IndexedDB 缓存课件、阅读页码、变式草稿和待完成任务，刷新后继续查询；切题后迟到结果不会显示到另一题。生成需联网；已缓存的内容可继续阅读与作答。清除浏览器数据会清除本机阅读与作答记录，后台课件仍可重新加载。

变式明确标记为 **AI 原创**，不附虚构真题年份或题号。后端检查三题完整性、章节关联、重复题干及数值答案与验算式的一致性；这不等于对物理语义、量纲或实验条件进行了独立人工审题。学习时应结合解析核对。

共享后台接口为 `/api/physics/health`、`POST /api/physics/lessons`、`GET /api/physics/lessons/<原题ID>` 和 `/api/physics/jobs/<任务ID>`，使用现有模型传输与进度机制。新增本机访问权限仅限 `127.0.0.1` / `localhost`，浏览器不接触模型密钥。安装目录中的物理扩展 ID 自动按 Chromium 规则识别；移动扩展目录后请一并移动同级 GESP 目录并重启后台，或使用共享服务的 `/physics/` 页面。

## 章节问答与 LLM 推荐问题

课程阅读页右侧新增“本节问答”。推荐的三个问题由共享后台的 LLM 根据本节正文、公式、例题和易错点生成，点击即可提问，也可自行输入并连续追问；没有使用固定问题冒充生成结果。首次进入本节自动请求，成功后按章节缓存，正文变更后重新生成。生成失败显示重试入口。

问答请求携带当前章节的教学内容和本节最近的有界对话历史，生成结果检查章节归属。对话、草稿和待完成任务按章节保存在 IndexedDB；切换章节不串话，刷新继续查询未完成回答，失败重试不会重复插入用户问题。模型密钥仍仅在 GESP 后台。缓存的旧对话可离线阅读，新的推荐问题和回答需要共享后台与模型可用。

物理页面顶部及问答连接失败处提供“启动／更新后台”，通过 GESP 已有本地组件启动同一服务并同步实际端口。首次使用运行一次同级 `gesp-lab-extension/enable-page-start.bat`，再在扩展管理页重新加载物理扩展（新增 `nativeMessaging` 权限）；GESP 安装器也会自动注册同级物理扩展。输入区与 GESP 一致，采用一体式圆角框、框内向上箭头发送，支持 Enter 发送、Shift+Enter 换行。

本节问答输入框提供与 GESP 一致的语音、图片、截图按钮。语音识别只填写草稿，需核对后发送；切页、收起问答或切到其他标签页时停止录音。不支持语音识别或服务不可用时，可在 Win11 输入框按 `Win + H`。应用不保存录音。

图片支持 PNG、JPG、WebP 选择与粘贴，每条最多 3 张，自动压缩至最长边 2000 像素、单图不超过 2 MiB（原文件不超过 8 MiB）。截图只截取当前章节正文，可框选后加入问题；附件先预览，可删除、仅发图片或补充文字。图片和草稿按章节保存，重试保留原图，不重复插入问题；模型请求最多携带最近三张图，使用 GESP 已配置的视觉模型。

问答标题处显示后台连接状态；失败原因刷新后保留。后台重启导致的旧推荐任务会重新获取，旧回答会明确提示重试。若扩展的后台权限尚未生效，会提示在 `chrome://extensions` 重新加载物理扩展。

## 课标与教学边界

七个模块是应用导航，不是课标原有一级主题。原课标包括“物质、运动和相互作用、能量、实验探究、跨学科实践”。页面标注相关条款范围，并链接原文。声学的来源核对记录见 [课标来源与映射](docs/curriculum-sources.md)，本版范围见 [内容与验证说明](docs/V2-COVERAGE.md)。

3D 使用真实 WebGL 网格、透视相机、深度与光照。动画是教学模型：音叉与悬球未作碰撞数值求解和自然衰减计算；空气比例与试听音量不代表真实压强或分贝；理想真空忽略支架传声；粒子运动慢放，粒子在原位附近往复振动。波形和试听共用归一化谐波系数，合成音不冒充真实乐器录音。信号峰值相同不保证能量或主观响度相同。

图形不可用时显示恢复入口，不用二维图冒充三维。若持续失败，可检查 Chrome 的图形加速设置；知识讲解仍可阅读。

## 隐私与依赖

- Manifest V3，无网页注入；AI 讲解访问本机 GESP 共享后台，由后台调用已配置的模型。语音输入在点击后由浏览器申请麦克风权限并使用浏览器语音识别服务。
- 运行资源全部随扩展附带；没有 CDN、远程脚本、账号、密钥、跟踪或遥测。
- `localStorage` 保存已学标记、最近作答、实验记录、笔记、实践报告和导航偏好。清除扩展数据、卸载或更换安装路径后可能失去进度；没有云同步。
- 试听只在用户点击后生成，最长 2 秒，可主动停止。请从较低设备音量开始。
- 课程和实验离线可用；“打开课标原文”是用户主动打开的外部 PDF 链接，需要联网。

