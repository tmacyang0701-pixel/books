# CodeArena GESP 学习工作台

等级学习页采用紧凑的 rem 布局，间距随视口高度调整；等级选择位于右上角下拉菜单，切换后同步更新学习内容与题库，并保存选择。统计合并为一行，学习目标按需展开，推荐题采用紧凑列表。普通笔记本窗口尽量一屏展示，较小窗口或放大字体时仍可滚动访问全部内容。

题库页的等级、场次、知识点、搜索和导入位于同一栏，窄窗口自动换行。左侧为窄幅双行题目列表，右侧加宽题面，日期与等级并入标题行，示例输入输出并排展示，来源说明按需展开；操作按钮固定在题面底部，不覆盖正文。滚动条统一为细条，学习页与题面正文的滚动条靠近窗口右边缘。

学习页显示两列六道推荐题，小窗口自动单列。知识点页使用右上角等级下拉和紧凑学习卡片；课件、练习和编辑器统一采用视口内布局。课件页的“目录”、编辑器上方的“题面”可独立收起并记住状态。顶部栏收起后，服务菜单平时贴右侧缩为状态点，悬停或聚焦时展开，点击后提供启动、设置和上传；连接状态每 30 秒及页面重新可见时更新。编程页的题目操作菜单位于左侧题面右上角，编辑器与结果栏标题齐平。问答推荐问题单行省略，悬停显示完整问题。

课件标题与目录合并，课件操作集中在目录底部工具抽屉；目录收起后仍可使用工具。正文顶部固定显示页类型、上一页、页码、下一页、朗读和讲稿入口，正文独立滚动，讲稿以抽屉打开。右侧问答可收起并记住选择，通过边缘图标恢复。聊天工具栏及输入框操作使用带说明的图标，语音、图片、截图和发送均在输入框内；不再显示常驻存储说明，实际存储错误仍会提示。页面通过本机 `@font-face` 使用微软雅黑，代码保留等宽字体；正文四周保留内边距。服务悬浮球采用固定悬停区域，展开时不会因边界移动反复跳动。

编程页题面右上角另有收起箭头，收起后通过编辑器上方“展开题面”恢复，与原布局偏好同步保存。

页面按当前浏览器视口布局，窗口边缘没有整页滚动条。首次打开默认收起左侧菜单和顶部栏；左侧两个图标可分别展开或收起，手动切换后记住选择，刷新或重新打开继续保持。两者都收起时，左侧窄栏仍可展开。题库列表、题目详情、课件正文、问答与代码区域按需内部滚动，适应笔记本窗口缩放。

本副本已整合到上一级 GESP 安装包。首次运行上一级的 `一键安装.bat`，Chrome 加载本 `extension` 目录；上一级的 `打开GESP.cmd` 用于日常打开。安装器复用原 `runtime-selection.json` 中可用的 Python/编译器，优先校验并使用上一级 `python/`、`devcpp/` 里的安装文件以及 `python/wheels/` 的离线 PDF 依赖，不要求 Node.js。原数间应用保留在 `application/`，详见上一级 `README.txt`。

本次复制的是干净运行文件，旧安装的密钥、课件、浏览器聊天和组件注册不在本包中。首次加载新路径后，以 Chrome 当前显示的扩展 ID 完成注册。

“讲解课件”为独立列表页，支持 GESP 1～8 级和标题关键词联合筛选、清除筛选及匹配数量。选中课件后进入阅读页，顶部不再显示横向历史卡片；返回列表保留当前筛选条件。

课件正文、表格、讲稿、示例解释及问答建议支持公式与行内代码排版。兼容旧课件中被 JSON 转义损坏的乘号等数学命令，保留 C++ 源码和样例输入输出原文。导出 HTML 使用本地生成的 MathML，不依赖联网、外部字体或脚本。旧课件刷新页面即可应用，无需重新生成。

新增独立“知识点讲解”导航，按 GESP 1～8 级选择。等级页、题目卡片和题干标签也可进入；从 5 级进入就固定按 5 级及前序基础讲解。专题采用原理、C++ 语法、示例、动手实践、易错、总结结构。每个语法页逐项解释符号，附可编辑并运行的小实验，代码和输入按课件页自动保存在浏览器。运行核对当前示例输出；修改输入后只展示实际输出。参考完整答案仍独立锁定。

组合标签先拆为单个知识点；已有题目课件仍可跳到匹配页面。同知识点、同等级使用固定关联，重新生成成功才替换旧专题。旧专题会提示“按新版结构重新生成”。可选图表缺失或无效时不再阻断有效课件；语法说明、实验任务、程序框架和预期输出仍严格校验。

专项练习先从题库按知识点标签匹配，以本级优先、前序基础为补充；含其他算法标签的题不作为单点练习。如果没有合适的题，才出现“生成 3 道专项练习”，由 LLM 生成入门、巩固、边界题。生成题标为 AI 原创，保存到本机，刷新后继续使用；失败不保存半成品。题库筛选基于现有标签，AI 练习的题意和测试点仍需教学时核对。

编辑器右上角“代码分析”会对当前代码快照做静态审阅，在大弹窗中按行标注错误、风险和修改方向。默认需密码；也可在当天同一道题达到有效修改后未通过评测次数及等待时间后免密。时间从首次有效修改后未通过评测持续计时，弹窗显示每秒更新的倒计时；次数和时间同时达标后点击“免密分析”，不会自动调用模型。只统计“提交评测”的未通过结果（包含部分通过、编译错误、运行错误和超时）；普通运行、仅改空格或注释、重复版本、网络错误不计次数，已通过的题目结束当前失败序列，每天本机零点重置。

点击“分析设置”，输入当前分析密码后，可配置等待分钟数、有效修改后未通过评测次数与新密码。安装默认值为 15 分钟、6 次，初始分析密码为 `WKN%sy24`；保存在 `learning_service/config.json` 的初始配置可由发行维护者调整。本机修改保存到 `.local/analysis-settings.json`，重启保留；新密码使用随机盐的哈希保存，不进入前端或模型请求。这些规则用于本机教学引导，不是防篡改考试认证；课件参考代码的显示锁独立。

升级后按新评测记录统计：旧版记录没有区分“运行”和“提交评测”，不计入新的免密次数；已有成功分析记录保留。

“分析记录”仅保存成功完成且匹配当前代码快照的分析，包含时间、代码版本摘要、解锁方式和标注数。取消、错误密码、模型错误、关闭未完成窗口都不记入；升级会清理旧版未成功记录，独立的失败练习统计不受影响。右侧课件问答栏会根据当前位置延伸到视口底部，保持 position: sticky，高度不超过可见视口；随滚动、缩放与全屏更新，消息在栏内滚动。末页练习入口位于左侧讲稿下方。

已有用户：在 `chrome://extensions` 重新加载 CodeArena，再点击页面“启动／更新后台”，加载服务版本 12 的知识点语法实验与表格兼容修复；无需重装依赖。

编程练习页在编辑器底部点击“调试”，会使用当前编辑器代码和右侧标准输入打开大窗口；修改代码或输入后可重新开始。调试期间暂停运行和评测按钮，关闭调试窗口后恢复。

调试按钮使用传统虫形图标。变量以紧凑行显示名称、类型和值，长类型悬停可查看，长值可在行内滚动；内存地址放入芯片图标的悬停说明，点击可展开或收起字节视图，数组和结构体仍可展开。低高度窗口同步压缩标题、工具栏和外围留白。

代码分析、变式练习和专项练习开启 Thinking，分析行号纠正及专项练习的自动补全也使用思考模式，思考预算 8192 Token；讲解和问答保持原模式。思考流只更新进度，不拼入 JSON 或保存原始思考内容，兼容没有 choices 的流式统计帧。接口依据：[百炼深度思考](https://help.aliyun.com/zh/model-studio/deep-thinking)、[结构化输出支持范围](https://help.aliyun.com/zh/model-studio/qwen-structured-output)。代码行号校验失败时按同一快照自动核对一次，仍不合法则拒绝展示，不硬截断行号。

专项练习模板使用两个各 50 分的测试点示例，与 2～5 个测试点、总分 100 的校验一致。缺字段、重复输入、样例不匹配等错误会自动核对一次，仍失败则报告具体题号和字段，整组练习不保存。后端修改需从服务菜单点击“启动／更新后台”生效。

课件代码也支持独立大窗口调试：解锁代码后，点击“运行代码”→“开始调试”。可设置断点、单步跳过、进入、跳出、继续，查看当前作用域的参数、局部变量、原程序全局变量及内存地址；数组和结构体可展开，地址可查看对象的前 64 字节。代码默认自动换行，可调整字号或“放大代码”暂时收起变量栏。关闭弹窗会结束本次调试；长时间未停下的单次执行会在 8 秒后终止。

标准输入旁的“换个用例”调用当前文字模型，按原题约束生成新输入、AI 预期输出及验算说明；失败保留原输入，生成成功后由用户运行或调试。代码栏的“解锁记录”按原题保存在 IndexedDB，同题重新生成或删除课件后仍保留成功解锁时间和对应页，不保存密码；记录不自动授予新课件查看权限。

在现有 Chrome C++ 本地评测扩展上增加：GESP 1～8 级学习导航及历年编程题、上传题目、千问讲解课件、相似题与原创变式练习。运行结果在右侧可展开／收起，错误点可查看输入、预期输出与实际输出。

## 开始使用

1. 完整解压新版安装包到本机可写目录，例如 `C:\CodeArena`；本地组件已包含在 `extension\native-host` 中。已有 Chrome、Python、GCC 会直接复用。
2. 首次双击包根目录的 **`一键安装.bat`**（或 `extension\install-all.bat`）。安装器检查系统和项目文件，下载并校验缺失的 Chrome、Python、带 GCC 的 Dev-C++，安装 Python 依赖，再注册扩展并启动学习服务。失败会说明原因并停止后续步骤。首次按提示填写百炼配置；安装软件时可能需要确认 Windows 权限提示。
3. 首次安装时，按提示在 `chrome://extensions` 开启开发者模式，选择“加载已解压的扩展程序”并选中本 `extension` 目录，将 CodeArena 卡片上的 **32 位扩展 ID** 粘贴到安装窗口。之后会复用记录的 ID。看到 `Ready` 和 `Installation complete` 后，在扩展管理页点击重新加载，再打开 CodeArena。
4. 在等级学习中选级别，进入真题库；选择题目后点击“生成讲解课件”。也可通过右上角“上传题目”使用 JSON、TXT、Markdown、图片或文本 PDF。识别结果确认后再生成。
5. 逐页查看课件、播放图解动画、展开讲稿、朗读或导出独立 HTML。右侧“本页问答”可以解释当前知识点和当前动画步骤，每页独立保存聊天。C++ 代码块点击“运行代码”，会在右侧显示输入和运行结果。最后一页点击完成学习，会推荐共同知识点的真题；还可以生成三道原创变式。

支持 Windows 10 1809 及以上、Windows 11 的 Intel/AMD 64 位环境，需要联网和安装权限。未在全新 Windows 虚拟机完成整套验收；当前已验证检测逻辑、失败停止、真实本地组件和编译运行。完整流程、依赖和限制见 [Windows 安装说明](docs/install-windows.md)。运行应用不需要 Node.js、npm 或数据库。

安装完成后，电脑重启也只需打开 Chrome 扩展，点击页面右上角 **“启动／更新后台”**。服务设置和问答错误处也有入口；页面显示进度与具体失败原因。旧版已安装用户需先运行一次 `enable-page-start.bat` 更新注册，不需要重新安装 Python 或编译器。`start-learning.bat` 和 `restart-learning.bat` 仅保留作兼容入口。

注册或重启前必须通过：项目及题库完整、Chrome、可运行的 Python 3.10+、GCC 实际 C++17 编译运行、`pypdf`、百炼配置及网络连通性。缺失应用自动补装后再次验证，不可用则停止。Python 依赖安装到项目 `.venv`，本地评测通过 `native-host/start-host.bat` 调用 Python 源码，不需要打包 EXE 或 PyInstaller。注册前验证真实消息协议、编译运行和 GDB 调试；已有安装可双击上一级的“修复本地评测.cmd”更新注册。网络预检不使用密钥；HTTP 401 表示地址可达，不代表模型权限已通过。

可只做本地检测（不安装、不重启、不访问模型端点）：`powershell -NoProfile -ExecutionPolicy Bypass -File .\install-all.ps1 -CheckOnly -SkipNetwork`。完整检测去掉 `-SkipNetwork`。检查结果保存在 `.local/install-check.json`。

已生成的课件可从左侧“讲解课件”进入，也可在原题详情点击“查看课件”。**同题只展示一份当前课件**；重新生成成功后替换旧版，失败仍保留旧版。课件卡片支持删除，原题不受影响。升级时已有同题多版本自动保留最新一份，旧版和删除的课件 JSON 归档到 `.local/lesson-archive/`，不会再出现在课件列表。课件的本机问答记录会随删除或替换清理，新课件开始新对话。

图解由受控 SVG 数据绘制，适合步骤的页面支持播放、暂停、上一／下一步。已有哥德巴赫课件直接补充筛法、配对计数、去重和流程图，无需重新生成；其他旧课件可根据已有步骤表生成演示。代码上方可展示“伪代码示例”和小输入的演算过程，现有哥德巴赫课件也直接补齐。新课件会要求模型在适合的页面生成图解或动画，模型返回无效图解时仍保留文字课件。导出的独立 HTML 保存静态图解和伪代码，不包含本地运行、聊天或动画控件。

聊天历史、草稿与待完成任务 ID 保存在当前浏览器的 IndexedDB，以“课件 ID + 页码”区分。刷新后恢复，切页不会串话；清除浏览器数据会移除这些本机记录。页面采用浅色主题。

问答输入栏支持“语音”“选择图片”“截取课件”，也可以直接粘贴剪贴板图片。语音使用浏览器识别服务转换为可编辑文字，首次需允许麦克风，不自动发送；网络不可用时可点输入框后按 Win + H。截图仅取当前课件，预览后可拖动框选，再加入问题。每次最多 3 张 PNG/JPEG/WebP，上传原图最多 8 MiB，前端缩放到每张不超过 2 MiB。图片草稿和历史也按页存入 IndexedDB。图片发送后由现有 `visionModel`（默认 `qwen3-vl-plus`）结合当前页答疑，纯文本仍使用配置的文字模型；需端点有对应视觉模型权限。旧后台会提示更新，不会静默忽略图片。

问答中的 LaTeX 公式通过本地打包的 KaTeX 渲染，包括已有历史的下标、分式等。行内代码和 C++ 代码围栏保持原文，不执行模型给出的 HTML。数学资源无需联网下载。

问答建议随当前页的知识点切换：筛法、去重、代码边界、复杂度等各有具体问题。新课件每页保存 3 个专属启发问题；旧课件根据当前页内容提供建议，无需重新生成。学伴默认采用苏格拉底式引导，一轮给一个小提示或问题，根据学生回答继续；卡住时增加提示或示范，明确要求完整解释时直接回答。

伪代码使用“方案数”“高糖偏差总量”等中文变量名，例子使用相同名称；新生成规则要求解释含义或单位。已有课件中的常见缩写提供中文显示，完整 C++ 代码保持其编程标识符；课件正文会在刷新列表时从本机服务重新加载。

“原题示例参考”只在读题、样例分析及实际引用样例的页面出现，不在代码、复杂度、总结页重复。新课件用 `useOriginalSample` 明确标记，旧课件按内容判断。饮品调制推演页提供原题、小数用量、含糖量全都正好、只有高糖原料 4 个可切换示例；贪心页另有“先取偏差小的原料”对比例子，可播放、暂停、单步查看取用量和累计体积。新课件可在合适页生成 2～3 个补充示例及动画。HTML 导出保留各例子及最终静态图解，教学示例与官方数据分开标注。

完整 C++ 代码默认锁定，点击“输入密码查看”并验证后显示，运行入口同时开放；伪代码与图解可直接阅读。解锁按课件与页码区分，仅在当前页面会话中有效，刷新后重新锁定，也可点击“重新锁定”。导出含完整代码的 HTML 前也需要解锁，导出文件本身包含明文代码。此功能用于课堂控制答案展示，是前端展示锁，不是对本机课件文件或学习服务接口的访问认证；密码不写入浏览器存储或展示在页面上。

讲解使用 `qwen3.8-max`，图片识别使用 `qwen3-vl-plus`。默认从 `~/lfun-github/explanation/.env` 读取 `DASHSCOPE_API_KEY` 与 `QWEN_BASE_URL`，不修改 explanation 项目、不把密钥写入前端。可用 `EXPLANATION_ENV_PATH` 指定原配置文件；模型可在 `learning_service/config.json` 或不提交的 `config.local.json` 调整。`CODEARENA_QWEN_MODEL` 可覆盖讲解模型。

本机 `learning_service/.env` 可设置 `ALIBABA_BAILIAN_API_KEY`、`ALIBABA_BAILIAN_MODEL`、`ALIBABA_BAILIAN_OPENAI_COMPATIBLE` 三项，分别指定百炼密钥、模型与兼容接口地址。这些配置优先于 explanation 配置；系统环境变量优先级最高。当前本机已按用户要求设置为专属百炼地址与 `qwen3.7-plus`。密钥文件已被忽略，不纳入版本控制。

启动脚本会先检查模型地址的网络连通性，不发送密钥、不产生模型 token。返回 HTTP 响应仅表示地址可达，模型权限与额度仍以生成任务为准。若显示错误 `10013`，表示 Windows 拒绝当前 Python 进程联网，不是普通响应超时；请从 Windows 正常用户会话双击启动脚本，仍失败时检查安全软件对该 Python 程序的联网限制。诊断保存在 `.local/network-check.json`，也可单独运行 `python -m learning_service.doctor`。

重启电脑后，从 Chrome 扩展页面点击“启动／更新后台”即可。关闭扩展不影响已提交任务；重新打开可恢复任务进度。服务中断时，未完成任务标记失败，可重试。已生成课件保存在 `.local/lessons/`，变式保存在 `.local/practice/`，不会被失败任务覆盖。代码按题目分别自动保存到当前浏览器。

如果通过 `http://127.0.0.1:8766` 查看页面，可在服务已运行时使用学习模块；页面启动后台和 C++ 评测需在已注册的 Chrome 扩展内使用。无需发布网站或连接数据库。

## 题库与来源

- `data/gesp/levels.json`：1～8 级学习导航，参考 [CCF 认证大纲](https://gesp.ccf.org.cn/101/1008/10012.html)，是整理概览而非大纲原文。
- `data/gesp/index.json`：题库索引。
- `data/gesp/level-1` 至 `level-8`：共 216 道 C++ 历年编程题整理版，每题一个 JSON。一级、二级各 30 道（2023-03 起）；三级、四级各 28 道（2023-06 起）；五级、六级各 26 道（2023-09 起）；七级、八级各 24 道（2023-12 起），均截至 2026-09。没有收录选择题、判断题或完整试卷；原卷与题面来源见每题链接。`coverage.json` 列出每级场次。
- 题面依据 [CCF 真题目录](https://gesp.ccf.org.cn/101/1010/index.html)及公开题面整理。每条记录保存原卷（已查得时）、题面核对链接、场次与日期。官方 PDF 在本次环境部分无法访问；没有用模型补造原题。
- 示例与 268 个练习测试点均为本项目自编，非官方隐藏数据。它们用于基本练习，得分不代表官方考试成绩。AI 原创变式另行标注，生成的测试点尚未独立验证。

`scripts/build_question_bank.py` 可重建全部题库；`scripts/build_all_question_bank.py` 从各级整理文件重建新增题目与索引，保留已有五级题目 ID。`scripts/collect_gesp_sources.py` 用于有联网权限的环境下载官方原卷供维护核对。扫描 PDF 暂不做自动 OCR，请转为题目图片上传。文本文件可直接粘贴，也可上传后编辑输入输出格式。
