| 光学 | 2.3.3—2.3.6 | 反射、折射、平面镜、透镜、光的组成 |
| 热学 | 1.1、3.3 | 物态、温度、内能、热传递、比热容 |
| 力学 | 1.2—1.3、2.1—2.2、3.2 | 基础物质属性与测量、运动、力、压强、浮力、功、功率、机械能 |
| 电学 | 2.4.1、3.4 | 静电、电路、电流、电压、电阻、欧姆定律、电功率、焦耳定律、安全用电 |
| 磁学 | 2.4.2—2.4.6 | 磁场、电流磁效应、磁场对电流作用、电磁感应、电磁波 |

## 模型假设

- 音叉：叉股振动及悬球运动作定性示意，时间放慢、振幅放大，不模拟材料弹性本构、碰撞细节、衰减或声压场。相对振幅没有长度单位。
- 真空罩：电铃保持工作；“空气保留比例”是教学控制量，粒子个数和音量线性调节都不代表真实压强或声级规律。理想真空步骤不考虑支架传声；现实抽气设备通常无法做到绝对真空。
- 声特性：同一对照步骤固定其他参数。纯音为正弦，另两种合成音添加固定谐波并以密集采样近似归一化峰值；波形图、粒子示意与 Web Audio 共用系数。相同峰值不保证能量、实际设备输出或主观响度相同。
- 传播：空气粒子在原位附近沿传播方向振动；示意将振动缩慢，波形图采用真实频率和固定 12 ms 横轴。模型未求解完整三维声场。
- 回声测距：发声与接收同处，障碍物静止，往返声速相同，`d = vt/2`。340 m/s 对应约 15 ℃ 空气，1500 m/s 是水中示例给定值。
