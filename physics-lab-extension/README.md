# 物理实验室 · Chrome 扩展

独立的初中物理离线学习扩展，按《义务教育物理课程标准（2022年版）》组织七个模块：64 节讲解与自测、48 个 WebGL 三维交互实验、10 个实践项目。不需要启动原项目后端，支持笔记本和小屏幕。当前版本 2.1.0。

## 安装与打开

1. 在 Chrome 地址栏输入 `chrome://extensions`。
2. 打开右上角“开发者模式”，点击“加载已解压的扩展程序”。
3. 选择本目录（有 `manifest.json` 的这一层）：

   ```text
   C:\Users\TMACY\Desktop\gesp\number-garden-one-click-setup\books\physics-lab-extension
   ```

4. 在 Chrome 工具栏的扩展菜单中找到“物理实验室”，点击图标，在独立标签页中打开。也可以通过扩展的“选项”打开。

不需要安装 npm 依赖或编译。更新代码后，在扩展管理页点击该扩展的重新加载按钮，再刷新学习页面。不要直接双击 `index.html`，浏览器的文件协议会限制 JavaScript 模块加载。

45 个新增实验均采用三维网格、深度、光照和透视相机，提供参数调节、实时读数、三步探究、最多 12 组记录及笔记。步骤会实际切换实验条件；动态过程手动播放，静态光路等实验通过参数与对照步骤观察。知识地图列出 22 类学生实验的模型入口，实物测量、小制作和调查由 10 个实践项目提供材料、过程、证据要求及报告。完整范围见 [内容与验证说明](docs/V2-COVERAGE.md)。

左上角按钮可收起模块导航；窄屏以抽屉显示，支持关闭按钮和 Esc。课程上一节／下一节、实验记录／重做／播放按钮随滚动保持可达。各模块独立显示进度、课程检索和自测成绩。

声学涵盖声音的产生、传播、声速与回声、音调、响度、音色、声的利用、噪声控制。提供知识点检索、回声测距计算器、噪声措施分类、已学标记与本机实验笔记。

三个声学实验分别是：

- **音叉与悬球**：静置 → 敲击观察 → 止振 → 再敲击，使用转换法呈现振动证据。
- **真空罩中的电铃**：保留空气 → 减少空气 → 理想真空 → 放回空气，保持声源工作状态不变。
- **声的三个特性**：建立基准 → 只改频率 → 只改振幅 → 改变谐波组成 → 自主探究，包含真实频率的合成音试听和统一时间窗口的波形图。

鼠标拖动或单指拖动旋转，滚轮或双指缩放；画布获得焦点后，方向键旋转，`+` / `-` 缩放，`Home` 复位。实验可在页面内展开，点击退出或按 `Esc` 返回。每步需手动播放；切换步骤、修改参数、离开页面、隐藏标签页时停止动画和试听。

## 课标与教学边界

七个模块是应用导航，不是课标原有一级主题。原课标包括“物质、运动和相互作用、能量、实验探究、跨学科实践”。页面标注相关条款范围，并链接原文。声学的来源核对记录见 [课标来源与映射](docs/curriculum-sources.md)，本版范围见 [内容与验证说明](docs/V2-COVERAGE.md)。

3D 使用真实 WebGL 网格、透视相机、深度与光照。动画是教学模型：音叉与悬球未作碰撞数值求解和自然衰减计算；空气比例与试听音量不代表真实压强或分贝；理想真空忽略支架传声；粒子运动慢放，粒子在原位附近往复振动。波形和试听共用归一化谐波系数，合成音不冒充真实乐器录音。信号峰值相同不保证能量或主观响度相同。

图形不可用时显示恢复入口，不用二维图冒充三维。若持续失败，可检查 Chrome 的图形加速设置；知识讲解仍可阅读。

## 隐私与依赖

- Manifest V3，无主机权限、无网页注入、无麦克风权限，不访问原项目接口或模型服务。
- 运行资源全部随扩展附带；没有 CDN、远程脚本、账号、密钥、跟踪或遥测。
- `localStorage` 保存已学标记、最近作答、实验记录、笔记、实践报告和导航偏好。清除扩展数据、卸载或更换安装路径后可能失去进度；没有云同步。
- 试听只在用户点击后生成，最长 2 秒，可主动停止。请从较低设备音量开始。
- 课程和实验离线可用；“打开课标原文”是用户主动打开的外部 PDF 链接，需要联网。

```text
manifest.json       Chrome 扩展声明
background.js       点击扩展图标时打开学习标签页
index.html          应用入口
styles.css          桌面与窄屏样式
src/curriculum.js   七模块目录、声学讲解与练习
src/full-curriculum.js  其余六模块讲解与自测
src/simulations.js  45 个交互模型和计算规则
src/simulation-view.js  器材示意、操作、记录与笔记
src/practice-projects.js  学生实验清单和实践任务
src/app.js          页面导航、学习进度、练习与小工具
src/lab.js          实验步骤、参数、播放、声音与笔记
src/world.js        三维网格、相机、渲染及实验场景
icons/             本地 PNG 图标
scripts/           基本检查、图标生成与打包工具
docs/              来源及基本验证记录
```

仅检查本扩展：

```bash
cd physics-lab-extension
npm run check
```

重新生成图标或分发压缩包（Python 3，无第三方依赖）：

```bash
python scripts/build_icons.py
python scripts/package_extension.py
```

压缩包输出到 `dist/physics-lab-extension-2.1.0.zip`，解压后加载其中包含 `manifest.json` 的目录。打包脚本使用白名单，不收集浏览器配置、实验笔记或临时截图。

本版进行课程完整性、模型数值及浏览器交互检查，见 [内容与验证说明](docs/V2-COVERAGE.md)。[首版验证记录](docs/validation.md) 保留作历史参考。未发布到 Chrome 应用商店，未修改用户常用 Chrome 配置。
