# 数间 · 专注训练与编程学习

保留 3×3 至 15×15 顺序寻数、位置记忆及限时读色训练，新增倒序数字、词语记忆和规则切换，三项新训练均可自由选择 1–10 级，由服务端调用百炼模型生成材料。

## 布局收起

右上角两个按钮分别控制左侧菜单与顶部区域。两处可独立收起，隐藏后按钮始终可见，可随时展开。左侧栏隐藏后主内容会扩大；顶部区域收起时品牌、介绍和训练导航一并隐藏。状态保存到当前浏览器，刷新后恢复，桌面、手机与数字训练全屏模式均可使用。

## 编程学习

通过 `#programming` 打开。参考用户指定的 `study-mate-agents/question-explanation` 的连续对话、解题路线、知识点弹窗与建议追问流程，适配为编程学习模块。没有复制该项目的宿主 SDK、认证、数据库或部署环境。

选择 Python、JavaScript / TypeScript、Java、C / C++、Go、Rust、SQL 或通用编程，以及 1–10 级学习难度。默认逐步引导，也可明确选择完整讲解。支持粘贴代码、导入 UTF-8 代码文本、定位报错、推演代码和检查边界；初始问题和代码在本题内保持稳定，后续输入作为追问或代码修订。

讲解正文通过 SSE 增量展示；仅展示模型公开 `content` 中的消息，不转发隐藏思考。上游明确成功、JSON 和路线完整校验后才作为完成回复保存。连接中断或生成失败时保留原消息，可手动重试；新草稿不会被迟到的回复清空。Markdown 和代码用安全 DOM 节点渲染，原始 HTML 不执行。

点击知识点可查看它与当前问题、步骤的关系；建议追问只填入输入框，不自动发送。可生成同类编程练习，并提交思路或代码，由模型静态分析评阅。这里没有代码执行沙箱，分数不代表实际编译、运行或测试通过。知识点和练习卡片带有七天有效的服务端签名，校验其所属问题；过期后可继续对话或重新出题。

最近 20 道问题与代码仅保存在当前浏览器，发送时由现有百炼配置处理。支持恢复、删除和新建对话；清除站点数据会删除本地历史。文本问题最多 6000 字符，代码最多 16000 字符，文件最多 100KB 且须为 UTF-8 文本。没有密钥时布局收起和原数字训练仍可使用，在线讲解需运行时密钥。

## AI 分级训练

| 训练 | 1 级 | 10 级 | 评分 |
| --- | --- | --- | --- |
| 倒序数字 | 每组 3 位，每位展示 0.94 秒 | 每组 12 位，每位展示 0.4 秒 | 倒序后的正确位置数 / 总位置数 |
| 词语记忆 | 4 个学习词 + 4 个干扰词，观察 14 秒 | 13 个学习词 + 13 个相近类别干扰词，观察 8 秒 | （正确选择 − 误选）/ 学习词数，最低 0 分 |
| 规则切换 | 10 题、1 种规则，每题 7.5 秒 | 28 题、3 种规则，每题 3 秒 | 正确题数 / 总题数，超时不计分 |

所有得分折算为 0–100 分。倒序数字每轮 3 组，数字逐个展示后隐藏；词语记忆先学习再辨认，误选与遗漏分列；规则切换逐题展示单/双数、数值大小或是否为 3 的倍数，按钮和左右键均可作答。4 级引入第二种规则，7 级引入第三种规则。

服务端验证模型输出的数量、格式和规则覆盖，必要时只尝试一次格式修正；生成失败会提示重试，不使用本地题库冒充模型出题。题目附服务端签名，提交时重新验证并核算成绩。新训练的自动判分不额外调用模型。达到 80 分时建议尝试更高一级，不限制自由选择难度；该阈值仅是游戏进阶规则。

支持计时、暂停、提前结束、提交失败后重试，以及每种训练和级别的个人最佳。切到后台或打开训练指南会暂停当前计时阶段。最近 200 次分级成绩仅保存在当前浏览器，不上传作答历史。出题请求可取消；出题和计时期间会锁定训练切换，避免丢失当前阶段。当前训练通过 `#digits`、`#words`、`#switch` 直接打开。

## 读色训练

选择 30 / 60 / 90 / 120 秒及 12 / 24 / 36 题，允许麦克风后开始。只读字的颜色，按编号从左到右、从上到下朗读。每道题的文字与颜色均不一致。结束时限会自动提交，也可提前结束；切到后台会提前结束录音。

浏览器使用 MediaRecorder 录音，并转换成 16kHz 单声道 PCM WAV。服务端先通过 `qwen3-asr-flash` 转写，再使用 `qwen3.7-plus` 提取实际回答并给出反馈。服务端校验模型提取结果与转写颜色顺序一致，按服务端签名题目重新核算得分，避免模型捏造分数或补齐未回答题目。

得分 = 正确题数 / 总题数 × 100（四舍五入）。逐项位置固定，第 n 个颜色对应第 n 题；重复或改口也算一次回答，因此请不要跳题。未读完单列为未作答，超出题数的回答不计分。页面提供识别文字、逐题核对、回听与录音下载；模型失败时保留本次录音供重试。

录音仅用于本次请求，不写入应用服务器存储或本地成绩。最近 50 次读色成绩仅保存在当前浏览器。重新开始或离开页面会丢弃内存录音。清除浏览器站点数据会删除成绩，语音识别有误时可结合回听核对。训练成绩不代表医学评估。

## 本地运行与验证

无需安装依赖，使用 Node.js 22 或更新版本：

```sh
npm run dev
npm test
npm run build
node scripts/validate-artifact.mjs
```

开发地址为 `http://127.0.0.1:4173`。在线麦克风需要 HTTPS，本机回环地址也可使用。语音评分需要服务端环境变量，变量名及默认配置见 `.env.example`；本地服务从进程环境读取变量，不自动加载 `.env`。密钥不得写入 HTML、源码、构建输出或 Git。没有密钥时数字训练仍可使用。

## 部署

`.openai/hosting.json` 保留原 Sites 项目标识，已从静态站点迁移为 Worker ESM。运行时变量通过 Sites 配置：

- `ALIBABA_BAILIAN_API_KEY`：服务端密钥。
- `ALIBABA_BAILIAN_MODEL`：判卷模型，默认 `qwen3.7-plus`。
- `ALIBABA_BAILIAN_OPENAI_COMPATIBLE`：百炼 OpenAI 兼容地址。
- `ALIBABA_BAILIAN_ASR_MODEL`：语音识别模型，默认 `qwen3-asr-flash`。

源文件位于 `web/` 和 `worker/`，其中 `web/navigation.js` 统一切换训练，`web/gym.js` 与 `worker/gym.js` 实现分级训练。构建将页面、样式与交互嵌入 `dist/server/index.js`，复制托管清单到 `dist/.openai/hosting.json`。部署保留原站点的私人访问范围，由 Sites 执行访问控制。服务端限制录音长度及格式，验证题目签名并拒绝跨站请求。

接口文档：[百炼语音识别](https://help.aliyun.com/zh/model-studio/qwen-asr-api-reference)、[OpenAI 兼容模型调用](https://help.aliyun.com/en/model-studio/qwen-api-via-openai-chat-completions)。
